# Fernleihwunsch DGS
![](https://www.hs-hannover.de/fileadmin/HsH/Hochschule_Hannover/Organisation/Bibliothek/KSF/stempel_buechersendung.jpg?rbiFocus=mobile)
Sie möchten ein Buch im Leihverkehr bestellen? Lassen Sie sich ein [Guthabenkonto](https://www.hs-hannover.de/ueber-uns/organisation/bibliothek/services/fernleihe) zur selbständigen Bestellung einrichten. Alternativ können Sie auch das folgende Formular ausfüllen. Sollten Sie bereits über ein Fernleihkonto verfügen, nutzen Sie bitte dieses für Ihre Fernleihbestellungen.
Erhalten Sie innerhalb von 3 Tagen keine Rückmeldung zu Ihrer Fernleihbestellung, [kontaktieren](https://www.hs-hannover.de/ueber-uns/organisation/bibliothek/standorte-und-oeffnungszeiten#c26510) Sie uns umgehend.
Bitte beachten Sie: Alle Felder sind Pflichtfelder, außer sie sind "Optional" gekennzeichnet.
