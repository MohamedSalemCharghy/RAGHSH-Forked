#  Partnerhochschulen 
[ Betriebswirtschaft und Wirtschaftsinformatik ](https://f4.hs-hannover.de/internationales/partnerhochschulen/partnerhochschulen-abt-bwl-und-wi) [ Informatik ](https://f4.hs-hannover.de/internationales/partnerhochschulen/partnerhochschulen-abt-i)
Im Folgenden finden Sie eine Übersicht aller Partnerhochschulen der Fakultät IV, sortiert nach Ländern. Die Kürzel weisen darauf hin, mit welcher Abteilung die Kooperation besteht.   
Bewerbungen an einer Partnerhochschule können nur nach erfolgreichem Durchlaufen des zentralen HsH-Auswahlverfahrens erfolgen.  
Informationen zum Bewerbungsprozess erhalten Sie [hier.](https://www.hs-hannover.de/internationales/wege-ins-ausland/studierende/bewerbung-1)
