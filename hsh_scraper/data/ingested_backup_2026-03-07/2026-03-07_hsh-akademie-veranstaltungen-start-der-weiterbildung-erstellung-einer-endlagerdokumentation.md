# Start der Weiterbildung "Erstellung einer Endlagerdokumentation"
##  06.10.2025   
Details in Beschreibung 
In der Weiterbildung "Erstellung einer Endlagerdokumentation" an der HsH-Akademie der Hochschule Hannover erwerben Sie Fachkenntnisse zur Endlagerdokumentation radioaktiver Stoffe und machen sich mit den Anforderungen an Produkte, Behälter, Dokumentation und Verfahren vertraut. Denn radioaktive Abfälle beispielsweise aus Medizin, Forschung oder Stromerzeugung müssen sicher entsorgt und dokumentiert werden.

  * **Kursname:** Erstellung einer Endlagerdokumentation
