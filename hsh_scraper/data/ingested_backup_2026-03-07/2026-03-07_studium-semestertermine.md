#  Semestertermine an der Hochschule Hannover 
Auf dieser Seite finden Sie die Semestertermine und Fristen.  
**Das akademische Jahr ist in zwei Semester gegliedert:**
  * das Wintersemester (WiSe) beginnt zum 01.09. eines jeden Jahres
  * das Sommersemester (SoSe) beginnt zum 01.03. eines jeden Jahres


**Vorlesungsbeginn**
  * für das Sommersemester ist i.d.R. der 1. März eines jeden Jahres.
  * für das Wintersemester ist i.d.R. der 20. September eines jeden Jahres.

## Fristen
[ Antrag auf Befreiung der Langzeitstudiengebühren bis einschließlich  ](https://f3.hs-hannover.de/studium/semestertermine "Antrag auf Befreiung der Langzeitstudiengebühren bis einschließlich ")
  * 31.03. für das vorangegangene Wintersemester
  * 30.09. für das vorangegangene Sommersemester


[ Antrag auf Beurlaubung  ](https://f3.hs-hannover.de/studium/semestertermine "Antrag auf Beurlaubung ")
  * für das Sommersemester der 31.03.
  * für das Wintersemester der 19.10.


[ Antrag auf Erlass der Langzeitstudiengebühr  ](https://f3.hs-hannover.de/studium/semestertermine "Antrag auf Erlass der Langzeitstudiengebühr ")
Innerhalb eines Monats nach Vorlesungsende des jeweiligen Semesters (schriftlich).
[ Antrag auf Erstattung von Gebühren und Beiträgen aufgrund Exmatrikulation  ](https://f3.hs-hannover.de/studium/semestertermine "Antrag auf Erstattung von Gebühren und Beiträgen aufgrund Exmatrikulation ")
Innerhalb eines Monats nach Vorlesungsbeginn. Angelehnt an den tatsächlichen Vorlesungsbeginn.
  * für das Sommersemester: Vorlesungsbeginn: 01.03. Fristende: 31.03 eines jeden Jahres
  * für das Wintersemester: Vorlesungsbeginn: 20.09. Fristende: 19.10 eines jeden Jahres


[ Bewerbungsfristen ](https://f3.hs-hannover.de/studium/semestertermine "Bewerbungsfristen")
Für die Bachelor- und Masterstudiengänge der Fakultät III gelten aufgrund unterschiedlicher Bewerbungs- und Aufnahmeverfahren verschiedene Bewerbungstermine. Welche dies genau sind können Sie **[hier](https://f3.hs-hannover.de/studium/informationen-fuer-studieninteressierte/aufnahme-bewerbungs-und-auswahlverfahren)** nachlesen.
[ Bewerbung mit ausländischen Bildungsnachweisen (über uni-assist)  ](https://f3.hs-hannover.de/studium/semestertermine "Bewerbung mit ausländischen Bildungsnachweisen \(über uni-assist\)  ")
Wenn Sie über ausländische Bildungsnachweise verfügen, müssen diese für den Hochschulzugang geprüft werden. Die Online-Bewerbung inklusive Uploads der Dokumente ist bis zum
15.03. (für das Wintersemester) für alle Master-Studiengänge
15.05. (für das Wintersemester) für alle zulassungsbeschränkten Studiengänge
15.07. (für das Wintersemester) für alle zulassungsfreien Studiengänge (BIM, BMI)
15.07. (für das Wintersemester) für alle künstlerischen Studiengänge der Abteilung Design und Medien
15.11. (für das Sommersemester) für den Master-Studiengang Medizinisches Informationsmanagement (MMI)
bei [uni-assist](https://www.uni-assist.de/bewerben/online-bewerben/) einzureichen.
Weitere Informationen sowie Ansprechpersonen finden Sie [hier](https://www.hs-hannover.de/ueber-uns/organisation/akademische-angelegenheiten/studieninteressierte/bewerbung/bewerbung-mit-auslaendischen-bildungsnachweisen).
