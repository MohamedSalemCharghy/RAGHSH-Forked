#  Anmeldung zum Alumni-Netzwerk Soziale Arbeit 
Scrollen für mehr Infos! 
Über folgendes Formular können Sie sich kostenlos für das Alumni-Netzwerk Soziale Arbeit anmelden. Die Anmeldung kann jederzeit per E-Mail an Marie-Claire Jovanovic ([marie-claire.jovanovic(at)hs-hannover.de](https://f5.hs-hannover.de/ueber-uns/alumni-arbeit/alumni-soziale-arbeit/anmeldung-alumni-netzwerk)) widerrufen werden. Die Kontaktpflege erfolgt per E-Mail.
Hinweis an Absolvent*innen des BA Religionspädagogik und Soziale Arbeit: Wenn Sie sich zum Alumni-Netzwerk Soziale Arbeit anmelden, werden Sie von der Abteilung Religionspädagogik und Diakonie ebenfalls Informationen erhalten.
Bitte beachten Sie: Alle Felder sind Pflichtfelder, außer sie sind "Optional" gekennzeichnet. 
Weitere Informationen können Sie der [Datenschutzerklärung](https://www.hs-hannover.de/datenschutz/) der Hochschule Hannover entnehmen.
