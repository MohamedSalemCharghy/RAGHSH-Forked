Variablen, Rechenoperatoren und Klammern.

1. Klammern

### Brüche


- Um zwei Brüche zu **addieren** (oder

zu **subtrahieren** ), müssen die
Nenner gleich sein.


- Um zwei Brüche zu **multiplizieren**,

müssen jeweils die Zähler und die
Nenner multipliziert werden.


- Um zwei Brüche zu **dividieren**

(Doppelbruch), wird mit dem
Kehrwert multipliziert.

### Lineare Gleichungssysteme


  - Ein **Lineares Gleichungssystem** ist eine Zusammenstellung von linearen

Gleichungen mit denselben Variablen.

  - Ein allgemeines Verfahren zum Lösen von linearen Gleichungsystemen ist

das _Gaußsche Eliminationsverfahren_ .

  - Sehr einfache lineare Gleichungsysteme (insbesondere zwei Gleichungen

mit zwei Unbekannten) können mit folgenden Methoden gelöst werden:

    - **Einsetzungsverfahren** : Eine Gleichungen nach einer Variablen

auflösen und Ausdruck in eine andere Gleichung einsetzen.

    - **Addtionsverfahren** : Gleichungen umformen, so dass eine Variable

eliminiert wird, wenn die Gleichungen addiert (oder subtrahiert) werden.

  - Falls ein Widerspruch entsteht, hat das System keine Lösung.

  - Falls eine Identität entsteht, hat das System unendlich viele Lösungen.
