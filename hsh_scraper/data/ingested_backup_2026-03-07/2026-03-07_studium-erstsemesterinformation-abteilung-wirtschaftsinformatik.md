#  Erstsemesterinformationen Abteilung Wirtschaftsinformatik 
  

  
Herzlich Willkommen - liebe Studienanfänger*innen der Studiengänge BIS, VIF und MDT.  
  
Wir wünschen Ihnen einen guten Start sowie ein erfolgreiches Studium!   

  

## Mathematik-Vorkurs
Zur Auffrischung der Mathematikkenntnisse findet für alle Studienanfänger*innen der Bachelor-Studiengänge **Wirtschaftsinformatik (BIS)** und **Verwaltungsinformatik** **(VIF)** vor Vorlesungsbeginn ein viertägiger Vorbereitungskurs statt.
Die Teilnahme ist freiwillig, wird jedoch sehr empfohlen.
Weitere Informationen finden Sie [hier](https://f4.hs-hannover.de/service/formulare-und-informationen/abteilung-wirtschaftsinformatik/mathematik-vorkurs "Opens internal link in current window").
