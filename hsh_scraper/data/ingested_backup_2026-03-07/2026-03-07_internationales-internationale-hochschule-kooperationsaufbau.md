#  Kooperationsaufbau 
## Kooperationen
Die Hochschule Hannover pflegt zahlreiche Hochschul- und Fakultätskooperationen. 
Den Prozess zum Abschluss von Kooperationsvereinbarungen außerhalb des ERASMUS-Bereichs können Sie [hier ](https://www.hs-hannover.de/fileadmin/HsH/Hochschule_Hannover/Internationales/Kooperationsaufbau/2021-03-18_Prozess_Internationale_Kooperation_ausserhalb_Erasmus.pdf)nachlesen.
Den Prozess zum Abschluss von Kooperationsvereinbarungen innerhalb des ERASMUS-Bereichs, sogenannte Inter-Institutional Agreements, finden Sie [hier](https://www.hs-hannover.de/fileadmin/HsH/Hochschule_Hannover/Internationales/Kooperationsaufbau/ERASMUS_Prozess_zum_Abschluss_eines_Inter-Institutional_Agreements.pdf)
Kontaktieren Sie uns gerne, wenn Sie Fragen oder Beratungsbedarf haben.
