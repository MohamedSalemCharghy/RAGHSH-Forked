#  Kooperationen und Ausbildungsangebote 
## Kooperationsunternehmen
Für den Start in das duale Studium in den Studiengängen
  * [Ingenieurinformatik (IID)](https://f2.hs-hannover.de/studium/bachelor-studiengaenge/ingenieurinformatik-maschinenbau-dual-iid/)
  * [Konstruktionstechnik (KTD)](https://f2.hs-hannover.de/studium/bachelor-studiengaenge/konstruktionstechnik-dual-ktd)
  * [Mechatronik (MTD)](https://f2.hs-hannover.de/studium/bachelor-studiengaenge/mechatronik-dual-mtd)
  * [Produktionstechnik (PTD)](https://f2.hs-hannover.de/studium/bachelor-studiengaenge/produktionstechnik-dual-ptd)
  * [Wirtschaftsingenieurwesen (WID)](https://f2.hs-hannover.de/studium/bachelor-studiengaenge/wirtschaftsingenieurwesen-maschinenbau-dual-wid)


benötigen Sie zunächst einen Platz in einem Unternehmen. Je nach Studiengang ist die Integration einer Berufsausbildung verpflichtend - detaillierte Informationen dazu finden Sie auf den jeweiligen Studiengangsseiten.
Grundsätzlich kommen sowohl unsere Partnerunternehmen als auch weitere Betriebe infrage, mit denen bislang noch keine Kooperation besteht.
Sobald Sie einen Ausbildungsplatz gefunden haben und eine Hochschulzugangsberechtigung gemäß § 18 NHG vorliegt, ist Ihnen bei einer Bewerbung bis zum 31.08. ein Studienplatz an der Hochschule Hannover für das Wintersemester (Studienbeginn: 01.09.) sicher.
Bitte beachten Sie, dass viele Unternehmen ihre Auswahlverfahren bereits rund ein Jahr vor dem Ausbildungs- bzw. Studienbeginn starten.
Im Anschluss finden Sie eine Auswahl unserer Partnerfirmen mit Ansprechpartner:innen. Über das jeweilige Logo gelangen Sie direkt zu den Unternehmenswebsites oder zu aktuellen Stellenangeboten – dort erhalten Sie weitere Informationen zum Bewerbungsverfahren.
