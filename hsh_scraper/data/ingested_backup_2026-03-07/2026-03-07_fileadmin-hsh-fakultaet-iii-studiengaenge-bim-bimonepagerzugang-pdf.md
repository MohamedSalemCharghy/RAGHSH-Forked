## **Zulassung zum Bachelor-Studium Informationsmanagement an der** **Hochschule Hannover ohne (Fach-)Abitur**

# Zulassung

Menschen in Informations-, oder Medienberufen sowie u.a. Fachinformatiker*innen (vollst. Liste s.
u.) können auch ohne (Fach-)Abitur bzw. eine klassische Hochschulzugangsberechtigung
Informationsmanagement (BIM) studieren, wenn Sie


   - eine mindestens dreijährige Berufsausbildung abgeschlossen haben und im Anschluss
mindestens drei Jahre berufstätig waren (die berufliche Qualifikation muss eine fachliche
Nähe zum Informationsmanagement aufweisen) oder

   - eine Hochschulzugangsprüfung abgelegt haben.


Folgende Ausbildungsberufe ermöglichen einen Zugang zum BIM-Studium:

Bibliotheksassistent*in, Buchhändler*in, Fachangestellte*r für Medien- und Informationsdienste,
Fachinformatiker*in, Film- und Videoeditor*in, Informatikkauffrau*mann, Kauffrau*mann für
Bürokommunikation, Kauffrau*mann für audiovisuelle Medien, Mediengestalter*in Bild und Ton,
Verlagskauffrau*mann


(vollständige Liste hier).

# Anrechnung

Haben Sie sich für das Studium auf Basis einer vorherigen Berufsausbildung entschieden, können Sie
die Anerkennung bereits erbrachter Ausbildungsinhalte beantragen und so die Anzahl an PflichtWochenstunden im Semester zum Teil deutlich verringern. Je nach Ausbildungsgang sind dies
unterschiedliche Inhalte. Sprechen Sie uns gerne in Bezug auf Ihr persönliches Ausbildungsportfolio
an.

# Teilzeitstudium

Auch ein Teilzeitstudium ist möglich. Während des Teilzeitstudiums können maximal 50 Prozent der
vorgegebenen Credits eines Vollzeitstudiums erworben werden. Es kann höchstens eine
Verdoppelung der Regelstudienzeit des Vollzeitstudiums gewährt werden. Wenn ein Teilzeitstudium
erwogen wird, empfehlen wir eine vorherige persönliche Beratung zur Studienorganisation.
