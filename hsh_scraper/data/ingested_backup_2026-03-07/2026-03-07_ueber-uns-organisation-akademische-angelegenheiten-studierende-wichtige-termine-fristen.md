#  Termine & Fristen 
##  Auf dieser Seite finden Sie die Semestertermine und Fristen des Dezernats - Akademische Angelegenheiten 
Das akademische Jahr ist in zwei Semester gegliedert:
  * das Wintersemester (WiSe) beginnt zum 01.09. eines jeden Jahres
  * das Sommersemester (SoSe) beginnt zum 01.03. eines jeden Jahres

## Fristen
[ Rückmeldung für das kommende Semester ](https://www.hs-hannover.de/ueber-uns/organisation/akademische-angelegenheiten/studierende/wichtige-termine-fristen "Rückmeldung für das kommende Semester")
  * für das Sommersemester 01. Januar - 31. Januar eines jeden Jahres
  * für das Wintersemester 15. Juni - 15. Juli eines jeden Jahres


[Rückmeldung -> Aktuelle Semesterbeiträge](https://www.hs-hannover.de/ueber-uns/organisation/akademische-angelegenheiten/studierende/semesterbeitrag-und-rueckmeldung)
[ Gasthörerschaft ](https://www.hs-hannover.de/ueber-uns/organisation/akademische-angelegenheiten/studierende/wichtige-termine-fristen "Gasthörerschaft")
Antrag auf Zulassung
  * für das Sommersemester 31.03. eines jeden Jahres
  * für das Wintersemester 19.10. eines jeden Jahres


[ Antrag auf Erstattung von Gebühren und Beiträgen aufgrund Exmatrikulation ](https://www.hs-hannover.de/ueber-uns/organisation/akademische-angelegenheiten/studierende/wichtige-termine-fristen "Antrag auf Erstattung von Gebühren und Beiträgen aufgrund Exmatrikulation")
Innerhalb eines Monats nach Vorlesungsbeginn. Angelehnt an den tatsächlichen Vorlesungsbeginn.
  * Für das Sommersemester: Vorlesungsbeginn: 01.03. Fristende: 31.03 eines jeden Jahres
  * Für das Wintersemester: Vorlesungsbeginn: 20.09. Fristende: 19.10 eines jeden Jahres


[ Antrag auf Befreiung der Langzeitstudiengebühren bis einschließlich ](https://www.hs-hannover.de/ueber-uns/organisation/akademische-angelegenheiten/studierende/wichtige-termine-fristen "Antrag auf Befreiung der Langzeitstudiengebühren bis einschließlich")
  * 31.03. für das vorangegangene Wintersemester
  * 30.09. für das vorangegangene Sommersemester


[ Antrag auf Erlass der Langzeitstudiengebühr ](https://www.hs-hannover.de/ueber-uns/organisation/akademische-angelegenheiten/studierende/wichtige-termine-fristen "Antrag auf Erlass der Langzeitstudiengebühr")
Innerhalb eines Monats nach Vorlesungsende des jeweiligen Semesters (online über das Campusmanagement).
[ Antrag auf Beurlaubung ](https://www.hs-hannover.de/ueber-uns/organisation/akademische-angelegenheiten/studierende/wichtige-termine-fristen "Antrag auf Beurlaubung")
  * Für das Sommersemester der 31.03.
  * Für das Wintersemester der 19.10.
