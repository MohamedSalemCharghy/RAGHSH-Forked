[Der schwierige Nachweis von Nachhaltigkeit : Wie Nachhaltigkeit und deren Wirkung systematisch gemessen werden kann](https://serwiss.bib.hs-hannover.de/frontdoor/index/index/searchtype/authorsearch/author/Oppermann%2C+Christopher/start/0/rows/10/subjectfq/Leistungsmessung/docId/2904) (2023) 
[Oppermann, Christopher](https://serwiss.bib.hs-hannover.de/solrsearch/index/search/searchtype/authorsearch/author/Oppermann%2C+Christopher) ; [Adam, Patricia A.](https://serwiss.bib.hs-hannover.de/solrsearch/index/search/searchtype/authorsearch/author/Adam%2C+Patricia+A.)
Unternehmen, die sich ernsthaft mit Nachhaltigkeit beschäftigen, müssen den Nachweis erbringen, dass sie positive Effekte für die Gesellschaft erzielen. Damit ist eine ganzheitliche Wirkungsmessung unabdingbar. Sozialunternehmen sollten als Vorbild für eine solche Wirkungsmessung dienen. Eine wissenschaftliche Studie auf Basis der sog. „Ergebnispyramide“ kommt jedoch zu dem Schluss, dass selbst diese ihre Wirkung bisher kaum ganzheitlich messen.
